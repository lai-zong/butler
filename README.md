# butler —— 可审计的记忆治理与自进化系统

> 一个本地优先的个人 AI 管家：它记得你、替你办事，也能让你看见它记住了什么、为什么这样判断，以及何时应该忘掉。

第九届传智杯 **AI WEB 网页开发挑战赛** 参赛作品 · 官方方向 1（AI Agent 智能助手）

---

## 项目介绍

现有个人 AI 助手通常有两种极端：一种每次对话从零开始，另一种无差别累积记忆，越记越乱。butler 把“长期记忆”当作需要治理的资产：有用的记忆被强化，无用的记忆逐步休眠或归档，整个过程可查看、可干预、可回退。

本项目不是“换皮聊天框”，而是一个可本地运行的个人 AI 工作台：对话、工具调用、记忆、文件/知识库、审查与数据迁移都围绕同一条可追溯的事件链组织。

## 技术架构

```text
src/
├── core/          领域核心：事件流、会话、记忆、召回、演化、工具与权限
├── adapters/      模型、文件、桌面、MCP、存储、TTS 等外部适配
├── app/           Next.js App Router：主界面、控制台与 API
└── validate/      可执行验证脚本
```

关键设计：

- **事件溯源**：对话、工具调用、审查、记忆变更与设置快照写入本地事件流，状态可以由事件重放得到；
- **记忆治理**：全局硬约束、全局共享事实、敏感域、领域记忆分层管理；敏感域跨域使用需要逐次授权；
- **渐进演化**：记忆有适应度、休眠、归档与唤醒，不是只增不减的备忘录；
- **可审计**：过程、依据、工具调用和审查结论留在历史里；
- **单管家 + 工具**：不把多 Agent 编排当作创新，复杂任务通过受控工具循环完成；
- **本地优先**：记忆、会话与事件默认保存在本机；模型调用只发送完成任务所需的上下文。

## 安装运行指南

### 环境要求

```text
Node.js >= 20.11
pnpm 9.15.0
```

### 安装

```bash
pnpm install
cp .env.example .env.local
```

在 `.env.local` 中至少配置一个可用的对话模型：

```bash
# DeepSeek（默认）
DEEPSEEK_API_KEY=你的密钥

# 或 OpenAI 兼容端点
# MODEL_PROVIDER=openai
# OPENAI_API_KEY=你的密钥
# OPENAI_BASE_URL=https://api.openai.com/v1
# OPENAI_MODEL=gpt-4o-mini

# 或 Ollama 本地端点
# MODEL_PROVIDER=ollama
# OLLAMA_BASE_URL=http://127.0.0.1:11434/v1
# OLLAMA_MODEL=qwen3.5:4b
```

具体变量及默认值以 `.env.example` 为准。`.env.local`、真实 API Key 和 `.butler-data/` 运行时数据不进入版本库。

### 启动

```bash
# 开发服务器（自动打开浏览器）
pnpm dev

# 指定端口 / 不自动打开
PORT=3001 pnpm dev
BUTLER_NO_OPEN=1 pnpm dev
```

首次启动需要设置本机登录密码和找回问题。该密码仅用于本机访问控制，不是云端账号。

### 构建与检查

```bash
pnpm typecheck
pnpm lint
pnpm test
pnpm build
pnpm start
```

### 本地数据

运行时数据默认写入项目根目录下的 `.butler-data/`，包括事件流、会话、记忆、配置与本地认证信息。该目录已被 `.gitignore` 忽略，不应提交。

## 主要能力

- 多轮对话与流式反馈；
- 文件、搜索、网页、MCP 与桌面工具；
- 工具权限分级、动作确认与审计；
- 跨会话记忆、记忆候选/审核/冲突/遗忘权；
- 字面/语义召回与精排；
- 上下文压缩与工具结果剪枝；
- 领域反思、跨领域复盘与渐进式记忆演化；
- 图片输入，PDF/DOCX/XLSX/CSV 文档提取与知识库检索；
- 本地账号、TTS、定时任务、专注空间与数据导入导出。

## 边界与安全

- Web 主对话在没有 OS 沙箱时不提供 `run_command`，避免命令越界；
- OpenAI 兼容与 Ollama 当前只承诺非流式主模型，叙述流以 DeepSeek 为主；
- 音频文件不转写、视频理解不支持；
- 单用户本地应用，不宣称多用户隔离或公网 SaaS；
- 工具调用有权限档位、确认、路径守卫与审计记录。
